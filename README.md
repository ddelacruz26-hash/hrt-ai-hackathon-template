# HRT AI Prototype

## Description
This project is a simple Streamlit application created for the HRT AI Hackathon assignment. The purpose of the app is to demonstrate a basic web application using Python and Streamlit.

The app currently includes a simple user interface and serves as a starting point for future AI and data analysis features.

## Technologies Used
- Python
- Streamlit
- Pandas

## How to Run
1. Install the required packages:
pip install -r requirements.txt

2. Run the application:
streamlit run app.py

## Deployment
The application was deployed using Streamlit Community Cloud.
