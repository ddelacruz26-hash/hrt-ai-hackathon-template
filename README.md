# Military MWR Usage Dashboard

## Overview
This project is a Streamlit-based dashboard focused on Military Morale, Welfare, and Recreation (MWR) program usage across the Department of Defense. The dashboard provides visual insights into participation trends, activity satisfaction, military branch usage, and top-performing installations.

The goal of this project was to create an interactive data visualization tool that demonstrates how technology and analytics can support recreation management and decision-making within military communities.

## Live Application
https://hrt-ai-hackathon-template-8gtzl6hn5bkjg2fatjc6da.streamlit.app/

## Features
- MWR participation trends from 2019–2024
- Usage statistics by military branch
- Activity satisfaction scores
- Rank-category participation analysis
- Top military installations by activity participation
- Interactive activity explorer
- Data tables and visual charts

## Technologies Used
- Python
- Streamlit
- Pandas
- GitHub
- Streamlit Community Cloud

## Dataset Information
The dashboard uses sample educational datasets related to:
- Military branch participation
- MWR activity usage
- Installation participation rates
- Satisfaction scores
- Historical participation trends

## Purpose
This project was developed as part of the HRT AI Hackathon to demonstrate how data analytics and dashboard technology can improve visibility into recreation and quality-of-life programs.

## Running the App Locally
1. Clone the repository
2. Install dependencies
3. Run the application using:

```bash
streamlit run app.py
```
